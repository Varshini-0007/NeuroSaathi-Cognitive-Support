# SIH26003 — Screening Round Prototype

## Build a Functional UI Prototype for an AI Cognitive Gaming & Memory Assistance Platform

Create a polished, modern, interactive web-app prototype for the SIH problem statement:

**SIH26003: AI Cognitive Gaming & Memory Assistance for Dementia Patients**

Organization:
**Ministry of Development of North Eastern Region (MDoNER)**

Project name:

# NeuroSaathi

### "Remember. Connect. Live Independently."

---

## IMPORTANT

This is ONLY the **screening-round prototype**, not the complete final product.

Do NOT spend time building:

* real backend infrastructure
* real medical diagnosis
* real clinical prediction
* complex ML models
* real GPS tracking
* real face-recognition infrastructure
* hospital integration
* payment systems

Instead, create a **high-quality functional frontend prototype with simulated AI behavior and realistic demo data**.

The purpose is to demonstrate:

1. We understand the dementia problem.
2. We understand different cognitive domains.
3. We have designed a patient-centered solution.
4. We have started implementing adaptive cognitive games.
5. We have a clear AI architecture.
6. We understand caregiver requirements.
7. The concept can later become a full-scale healthcare platform.

The prototype must look like an actual early-stage healthcare technology product, NOT a generic college dashboard.

---

# TECH STACK

Use:

* React
* Vite
* TypeScript
* Tailwind CSS
* React Router
* Lucide React icons
* Recharts

Use local state/localStorage for demo data.

No external API should be required for the prototype.

---

# CORE CONCEPT

The application should support people living with dementia.

The initial prototype should be **Alzheimer's-oriented**, particularly around:

* memory
* recognition
* orientation
* attention

But the architecture should be designed around cognitive domains so it can later support other dementia profiles.

Do NOT claim the application diagnoses or cures dementia.

Display:

> "NeuroSaathi is an assistive cognitive-support and memory-assistance prototype. It does not diagnose or treat dementia and does not replace professional medical care."

---

# COGNITIVE GAME SCREEN

Title:

# Today's Cognitive Activity

Subtitle:

> "A few minutes of mental activity designed around your abilities."

Show three game choices.

---

# GAME 1 — REMEMBER THE OBJECTS

Cognitive domain:

**Memory**

Screen:

> "Look carefully at these objects."

Show:

🍎 Apple
🏠 House
🐕 Dog
☕ Cup

After 5 seconds, hide them.

Show multiple choices.

Question:

> "Which objects did you see?"

Patient selects answers.

Calculate a score.

Example:

**4 / 4 Correct**

Then show:

### Excellent! 🌟

Also display:

**Accuracy: 100%**

**Reaction Time: 2.1 sec**

---

# GAME 2 — FOCUS FINDER

Cognitive domain:

**Attention**

Show a grid of shapes.

Instruction:

> "Tap only the circles."

Include circles, squares, triangles and distracting objects.

Track:

* correct taps
* incorrect taps
* reaction time

At completion show:

**Attention Performance: 82%**

---

# GAME 3 — PUT IT IN ORDER

Cognitive domain:

**Executive Function / Sequencing**

Show cards:

* Wake up
* Brush teeth
* Eat breakfast
* Start the day

Allow the user to arrange them.

After completion:

Show:

**3 / 4 correct**
